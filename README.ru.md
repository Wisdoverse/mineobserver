## 🚀 Быстрый старт

### Требования

- **Node.js** ≥ 20
- **pnpm** ≥ 9

### Установка и запуск

```bash
# Установить зависимости
pnpm install

# Запустить сервер разработки (http://localhost:5000)
pnpm dev

# Сборка для продакшена
pnpm build

# Запустить продакшен-сервер
pnpm start
```

## 📡 Протокол WebSocket

**Эндпоинт:** `ws://<host>:5000/ws/agent`

### Агент → Сервер

| Тип сообщения | Описание |
|--------------|----------|
| `agent:register` | Регистрация или переподключение агента |
| `agent:status:update` | Отправка обновления статуса (допускается частичное) |
| `agent:event` | Сообщить о пользовательском событии |
| `agent:world:snapshot` | Отправить снимок мира |
| `agent:vision` | Загрузить скриншот |
| `agent:build:progress` | Обновить прогресс строительства |
| `agent:chat` | Отправить сообщение в чат |
| `agent:disconnect` | Корректное отключение |
| `ping` | Проверка активности |

### Сервер → Клиент

| Тип сообщения | Описание |
|--------------|----------|
| `agents:list` | Полный список агентов (при регистрации наблюдателя) |
| `status:update` | Широковещательное обновление статуса |
| `event:new` | Уведомление о новом событии |
| `world:snapshot` | Широковещательная рассылка снимка мира |
| `vision:new` | Уведомление о новом снимке |
| `build:progress` | Обновление прогресса строительства |
| `chat:new` | Новое сообщение в чате |
| `admin:data-cleared` | Уведомление об очистке данных |
| `pong` | Ответ на пинг |

> 📖 Полная спецификация протокола: [public/api-docs.md](public/api-docs.md)

## 🤖 Руководство по интеграции агента

Подключите ваш Minecraft-бот к MineWorld за 4 шага:

```
1.  Подключение    →  ws://<host>:5000/ws/agent
2.  Регистрация    →  { type: "agent:register", payload: { agentId, username, ... } }
3.  Статус         →  { type: "agent:status:update", payload: { agentId, status: {...} } }
4.  (Дополнительно) →  agent:vision · agent:build:progress · agent:chat · agent:world:snapshot
```

**Рекомендации:**
- Используйте **стабильный `agentId`** для переподключения без потери данных
- Отправляйте обновления статуса каждые **2–5 секунд**
- Загружайте скриншоты в формате **PNG с base64-кодированием**
- При отключении отправьте `agent:disconnect` или просто закройте сокет — офлайн-статус сохранится

> 📖 Полный справочник по полям и примеры: [public/api-docs.md](public/api-docs.md)
